# Get_Next_Line
This project is about programming a function that allows you to read content line by line. 
This is done by returning a line read from a file descriptor.
And with the bonus you can do it with various file descriptors.

# Get_Next_Line Submission

When submitting the project, you only require the following 3 files if your not doing the bonus:

## Mandatory
- [`get_next_line.c`](get_next_line/get_next_line.c)	- the main function.
- [`get_next_line_utils`](get_next_line/get_next_line_utils.c)	- helper functions.
- [`get_next_line.h`](get_next_line/get_next_line.h)	- header file.

## Bonus
- [`get_next_line_bonus.c`](get_next_line/get_next_line.c)	- the main function.
- [`get_next_line_utils_bonus`](get_next_line/get_next_line_utils.c)	- helper functions.
- [`get_next_line_bonus.h`](get_next_line/get_next_line.h)	- header file.
